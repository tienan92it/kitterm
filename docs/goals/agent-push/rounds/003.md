## Effects

- **There was no single place to hang it, and the crew said so rather
  than inventing one.** `mergedState` is computed at read time from three
  kinds of evidence, by design, so nothing knows it changed.
  `PushNotifier.observe` is therefore called where each kind changes:
  `HTTPAPIHandler.emitAgentStatus`, which already fires only on a hook
  transition; the `approval.pending` append; and the held decision's
  `whenComplete`, whether answered or expired. Each computes
  `MergedSessionState.merge` the way a row does.
- **`failed` had no event at all.** A `commandEnd` mark lands in
  `PtySession.handleOutput` and nothing fired. The crew added
  `PtySession.setCommandEndHandler`, set by the registry on every session
  it admits, fired off the lock once per command. Still no poller.
- **Dedupe lives in memory, and the argument is sound.** A restart ends
  every shell, so nothing that was waiting survives to be told twice. A
  takeover restores each session's last hook report, which gates the
  `agent.status` transition at its source. Persisting the table would
  guard against a case that cannot occur.
- **The rate limit drops rather than queues**: 4 per session per 60 s,
  logged. A human told four times in a minute is already looking at that
  session, and a queue would deliver a state it has left.
- **404 and 410 both forget the endpoint**, which is RFC 8030. The VAPID
  pair lives in `~/.kitterm/vapid.json` at `0600`, replaced and logged if
  it is not owner-only, because replacing it invalidates every
  subscription on every phone.
- **It measured the live feed rather than assuming the shape.** Real
  Claude Code sends `Stop` and then `needs-input` 60 s later, and sends no
  `Notification` beside a held `PermissionRequest`, so one ask produces
  one message.

## The Linux build, which round 2 had skipped

It failed on the first run, in exactly the class `facts.md` names:
swift-crypto's `P256.Signing.PrivateKey` is not `Sendable` where
CryptoKit's is, so `VAPIDKeys` could not be a plain `Sendable` struct.
The fix is one annotation with its reason written beside it: the key is a
`let` and is never mutated, so sharing the struct across threads is safe
on both platforms. The foreman read that justification rather than
accepting the annotation.

`Build complete! (49.87s)`, exit 0, from the `facts.md` pipe.
