## Effects

- **The rule is the local calendar day, not an elapsed span.**
  `stampFormat(epochMs, now)` answers `time` or `date-and-time`, and
  `restartNotice` takes the stamp function and the reference time as
  arguments. `sessions.ts` passes `clockTime` for `time` and
  `toLocaleString` for `date-and-time`, which is the convention
  `archivedFold` already follows. The crew's defence of the rule is
  right: a bare "10:35 PM" is unambiguous only while the death and the
  read carry the same date.
- **The midnight case is tested, and it is the one a span gets wrong.**
  A run that died at 23:50 and a page opened at 00:10 are eighty minutes
  apart and on different dates, so the line carries the date. There is a
  second case in the other direction: a run that died early today and a
  page read at 23:55 is nearly a day later and still shows the bare time.
  Eight new cases in all, built from local date parts so no timezone
  moves them.
- **The screenshots caused a real change.** A bare `toLocaleString`
  printed "9/6/2026, 11:09:03 PM". The crew changed it to `dateStyle` and
  `timeStyle` `short`, which prints "9/6/26, 11:09 PM", because the
  daemon writes the previous run's clock on a heartbeat and the seconds
  were false precision.
- **One suggestion taken, one refused with a reason.** `roundOf` now
  calls `wholeNumber`, so the parse exists once. The crew skipped the
  plural helper and said why: two of the three ternaries are a count plus
  a noun, but `needsYouMessage` also agrees the verb, so a noun-only
  helper would cover two sites and leave a ternary at the third. That is
  the second repetition, not the third, and this repository extracts on
  the third.

## Reflection

The round is small and the reason it exists is not. Round 3 was recorded
as done on a green floor and a real `kill -9`, and it still shipped a
line that lies to anyone who comes back on Monday. No test caught it,
because every test and every screenshot ran on the day the code was
written. That is the shape of the defect: a clock bug is invisible to a
suite that never crosses a date.

The reviewer found it by reading the formatter against its neighbour in
the same file, where `archivedFold` already handled a stamp that can be
old. The fix was one function and eight cases. The gap it closes is in
`facts.md`: a test that builds its fixtures from the current clock proves
only what is true today.
