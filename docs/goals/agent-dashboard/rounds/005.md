model. It is not, and the crew measured it before writing code.**

assistant turns. The crew searched for what it actually needed. The
reader uses **256 KiB**, and the foundation's sentence is a proposal for
the human below.

## Effects

- behaviour: a session's row carries its model as a fact, and
  `GET /api/usage/daily` answers a per-model split for the range.
- **Where the read sits, and what invalidates it.** One 256 KiB `pread`
  on `TranscriptBill.queue` — off the event loop and off the registry
  actor. `TranscriptModelCache` is keyed by path with a size+mtime
  fingerprint, so an unchanged file costs **one `stat`** and a changed
  file one read. A changed tail with no assistant line keeps the model
  that path last yielded; a path never seen yields **nothing**, never a
  guess.

  `unsplitUSD`, and **`Σ models + unsplit == total`** is asserted per

## Reflection

The round is the loop working as designed. A crew was handed a frozen
contract, measured the one number in it that could be measured, found it
wrong, used the right number, and reported the contract as a proposal
rather than silently following or silently diverging.

What made that possible was the shape of the error. "4 KiB is enough"
fails quietly — it returns *a* model for some sessions and nothing for
the rest, which looks like a session with no assistant turn. The crew
measured because the prompt asked what it had measured, not whether it
had.
