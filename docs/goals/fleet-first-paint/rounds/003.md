- `4844c7e`: the yield cache kept 64 entries for each route, but one

  16 roots each still read again.

  range showed as the new range's with `unread: 0`. It now serves an
  answer whose `to` is at most 7 days earlier, and `docs/http-api.md`

  false. The foreman's own change in round 2 made this fault.
- `29bf07f`: a non-ok answer of `/api/archives` emptied the page's list
  and the page did not ask again. It now keeps the list and its tag and
