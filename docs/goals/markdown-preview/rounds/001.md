## Effects

- behaviour: `parseMarkdown(text)` gives a block tree and never throws;
  `renderMarkdown(blocks, {resolveLink?, resolveImage?})` gives a
  `DocumentFragment` through `createElement` and `textContent`, with
  exactly the attributes of `RENDERED_ATTRIBUTES`. The default link
  rule lets `http`, `https` and `mailto` out in a new tab with
  `noopener noreferrer`, makes a relative `.md` path or a `#fragment` a
  document link (`data-markdown`), and makes every other scheme, `//`
  included, text; the scheme is read with whitespace, control bytes and
  case removed. No image loads by default. Heading ids are `md-` plus
  GitHub's slug (`fragmentTarget`, `HEADING_ID_PREFIX`). Fenced code is
  coloured through `tokenize` and the new `languageForFence`. A cut
  file parses as a prefix, an open fence to the end.
- measured: a 1 MB file parses in 58 to 94 ms and renders in 87 to
  104 ms (32,268 blocks); 10,000 of `>`, `*`, `**a* `, `[a](` and the
  rest finish in 0.1 to 21 ms; 1,000 nested list levels in 156 ms.
- simplified, by the crew's list: lazy continuation judged by the last
  inner line; a fence's blank line makes its list loose; no table
  interrupts a paragraph; 45 named entities; `~~` only; bare URLs
  `http` and `https` only; tabs expanded in leading space only; an
  empty `- [ ]` is a task; an HTML block is a paragraph of text.
- persistent: `markdown.ts`, `markdown.test.ts` (72),
  `markdown-security.test.ts` (36), `languageForFence` in
  `highlight.ts`. No Frozen, Propose or Chartered path.
- design: the human chose draft A of two browser drafts on 2026-10-16
  (`corpus/01-approved-design.md`, `corpus/draft-a-b.png`).

## Correction

One, before `DONE`: a heading's id was its bare slug, so a file with a
heading named `location` or `sessions` would put that id on the page,
where a browser exposes it as a global (DOM clobbering). Every id now
wears `md-`, and a security test pins `location`, `document`,
`sessions`, `__proto__` and `constructor`.

## Reflection

The foreman read the renderer's attribute and link code before `DONE`
and found the id fault there; a security suite that walks attributes
should also list the id values it allows, which this one now does.
