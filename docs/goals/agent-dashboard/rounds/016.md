## Proposals

- `ModelPricing.swift` is a rate table copied from a web page on one
  day. When Anthropic changes a rate, the estimate drifts and nothing
  says so. Either the human owns the table and a test pins its date,
  or a future round reads rates from a file the human edits.
- Read `<session>/subagents/*.jsonl` into the estimate. A session
  with subagents estimates up to 17% under.

## Reflection

The foreman asserted a fact about the code in a prompt without
reading the code. The crew caught it. Check the premise before naming
it as a constraint.
