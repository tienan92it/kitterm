## Two roundings the crew declared

- **The summed spend adds unrounded values**, so the printed total can
  differ from the printed parts by a cent — $325.51 against parts that
  sum to $325.52. Summing the rounded parts instead would make the panel
  disagree with the range total, which is worse.
- **The session count sums per-model counts**, as every row does, so a
  session that used two tail models counts twice. A distinct count needs
  the daemon and nobody asked for one.
