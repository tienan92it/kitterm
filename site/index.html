It keeps running.

Reload the page, restart the daemon, drop off Wi-Fi — the session is still there, and replays the exact bytes you missed. A long build doesn't need you sitting in front of it.

It follows you.

Open the same session on your phone and take control mid-command, right where the laptop left off. Or hand out a link that can watch and never type.

It answers to programs.

Every command is indexed with its exit code and its output, over plain HTTP. An agent can start a build, wait for it to exit, and read the result — instead of scraping a screen and guessing.

Local by default. kitterm binds loopback and checks Host/Origin, so no web page can reach your shell. Nothing leaves the Mac until you turn on sharing.
