## Prompt

Capability 3 of `plan.md`. `POST /api/usage/limits` takes the
`rate_limits` object a statusline render is given; the daemon keeps the
newest and serves it at `GET /api/usage/limits` with the age of the
reading. The installer teaches the statusline script to post it. The page
shows one bar per window with its reset countdown, and says plainly when
no reading has ever arrived. Proof: route tests for post, get, an absent
reading and a stale one; a vitest over the bar model including the
never-seen case; and one real reading captured from a live session.

## Effects

- behaviour: `kitterm statusline install` writes
  `<claude dir>/kitterm-statusline.sh` and points `settings.json`'s
  `statusLine.command` at it. The wrapper hands the same stdin to the
  command that was configured before, on a marked line a reinstall reads
  back, so the human's own script is never opened or rewritten. The
  wrapper posts the `rate_limits` object with one background `curl -m 2`,
  every fd closed, only when the object changed or a minute passed. It
  skips with no port file, no `jq`, or no `rate_limits`.
- The crew settled four questions inside its authority:
  - **Cost of a render.** Measured, n=20, the object varied so every
    render posts: the human's statusline alone 40.2 ms median, 45.9 p95;
    the wrapper with the daemon up 54.0 / 72.5; the daemon down
    60.2 / 64.9; no port file 52.8 / 58.5. About 14 ms a render, and a
    dead daemon costs no wait.
  - **Age.** The route answers `ageSeconds` always and marks a reading
    stale past 3600 s. The page prints "read 4m ago" under the bars. A
    stale reading keeps its bars, mutes the fill, and says to open a
    Claude Code session. A window past its `resets_at` draws empty and
    says "reset". `usage-limits.json` keeps the reading, so a restart
    keeps its true age.
  - **Grade.** Full only, as `GET /api/usage/daily` is: the reading is
    the account's accounting, which a watch token withholds. A watch page
    hides the block.
  - **Bar.** Text cells, `[#####...............]`, 20 cells at 5% each,
    the number beside. It is the terminal's own idiom, it adds no
    surface, and it cannot become a pill.
