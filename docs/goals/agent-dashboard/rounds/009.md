## Reflection

Twelve minutes and $2.94 for a one-word change, and most of that was
proving the three things that were **not** meant to move. That ratio is
right: the edit was trivial and the risk was entirely in what it might
have disturbed.

The base-daemon discrepancy is the round's real lesson. A measured
difference between two builds is only evidence if both builds are
measured under the same conditions, and a copied state directory is not
the same conditions.
