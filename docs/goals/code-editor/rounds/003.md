## Effects

- behaviour: `GET /api/files/content` sends `ETag: "sha256:<hex>"` of
  the whole file and `X-Kitterm-Mode` when the read is not truncated.
  `PUT /api/files/content?path=&session=` takes the new bytes (at most
  256 KiB) at full grade with `X-Kitterm-Editor: 1` and an Origin equal
  to the request's own; it resolves the path lexically, finds the
  project of the parent's realpath, walks below the shortest ancestor
  whose realpath is the root with `O_NOFOLLOW_ANY` (Darwin) or
  `O_NOFOLLOW`, and saves atomically (a random temp file, `F_FULLFSYNC`,
  `fchmod`, a re-check of the hash and the inode, `renameatx_np` with
  `RENAME_NOFOLLOW_ANY`) on the serial queue `kitterm.edit`. Answers:
  200 `{ok, etag, bytes, path}`; 412 with the current `ETag`; 428; 403
  for a watch token, no editor header, another Origin, outside every
  project, a symlink below the root, a path under `.git` in any case;
  404 for no file (no create); 409 for a FIFO, a directory or a hard
  link; 413. Each attempt past the grade writes one line to
  `~/.kitterm/edits.log` (0600, rotated at 1 MiB) with the time, the
  token kind, the path, the bytes, both hashes and the status, never
  the content. `FileBrowser.resolve` is unchanged, so the read and the
  listing still follow a symlinked directory.
- persistent: `FileEdit.swift`, `EditLog.swift`,
  `FileSaveRouteTests.swift` (26), the changes to `HTTPAPIHandler.swift`,
  `FilePreview.swift`, `AccessPolicy.swift`, `TokenStore.swift`,
  `DaemonPaths.swift`, `AGENTS.md`, `docs/architecture.md`. No Frozen,
  Propose or Chartered path.

## Correction

One, before the first edit: the plan made `FileBrowser.resolve` lexical
for every route, which would have broken the read and the listing
through `/tmp`, `/var` or a symlinked workspace, and a lexical path
never matched a realpath root. The read routes keep their resolver; the
save route allows a symlink above the root and refuses one below it,
pinned both ways.

## Reflection

The research named `O_NOFOLLOW_ANY` with `O_NOFOLLOW`; on macOS 26.6.2
the two together are `EINVAL`, a fact the crew measured before it
could ship a jail that opened nothing.
