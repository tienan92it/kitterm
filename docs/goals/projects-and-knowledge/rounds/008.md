## Gap

class: harness
evidence: three findings about the loop's own machinery, none about the
skill's procedure, which ran as written.
1. The MCP bridge's `send_input` drops the escape byte from a text, so a
   foreman cannot send an arrow key through it; the foreman of this goal
   answered the fixture pane's trust dialog through the HTTP input route
   with `printf '\033[B'`. The skill's "one Down arrow" step does not
   work over the bridge as shipped.
2. The pane's raw output stream is not a transcript: Claude Code redraws
   in fragments with cursor moves, so a search of the retained log or
   the output route for "Needs you" finds nothing although the pane
   showed it. The per-round digests could not be counted after the fact;
   only the final one was read from the rendered screen.
3. The standing foreman left its records uncommitted until told to
   commit. `LOOP.md` says the foreman writes the record; it does not say
   when to commit it.
