## Proposals

1. `design/foundation.md`, Colour, after the diff-line exception:
   "**A second exception: a file-type tag.** In the `/edit` tree
   (`design/editor.pen`, `Editor components 2` rule 17), the two- or
   three-letter tag before a file's name (`ts`, `md`, `sw`, `{}`) is
   set in the `--code-*` token of its language, the source view's own
   colours, over its glyphs alone. It names a kind, not a state: no
   state colour paints a tag, a folder and an unknown type carry no
   tag, and an ignored entry's tag is `--ui-text-faint`."

   matched letters in weight 600, underlined, in the text colour.
