## Effects

- **The rule, in one line.** The nearest ancestor of the cwd that is
  either a checkout or a registered root wins. Outside every checkout the
  longest registered root still wins.
- **The case the plan did not name.** A registered root *inside* a
  checkout is nearer to the cwd than the checkout, so it still names and
  configures its own tree. Without that case, registering a package
  inside a monorepo would be inert, which contradicts the plan's own
  sentence that a registered root still names the project it points at. A
  worktree under a registered folder is not this case: its checkout lies
  outside that folder, so the checkout wins.
