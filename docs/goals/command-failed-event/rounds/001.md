## Effects

- behaviour: `PtySession.handleRead`, under `stateLock`, at a `commandEnd`
  mark with a non-zero exit in an orchestrated session (API-spawned or
  labelled, read at fire time), runs one `SessionCommands.pair` pass and
  takes the command whose `endOffset` is that mark's offset; a mark that
  closes no command fires nothing. The handler runs outside the lock,
  before the waiters' promises, so a caller that waits on the command

  the handler when the registry has an event log; `PushNotifier` is
  unchanged. One pass per chunk serves both the waiters and the event.
