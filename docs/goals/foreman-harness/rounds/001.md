## Effects

- **The premise was wrong, and the round proved it.** `goal.md` says the
  MCP bridge drops the escape byte. It does not. The crew drove
  `.build/debug/kitterm mcp` with a hand-written JSON-RPC line into a
  pane running `xxd` and read the bytes back:
  - `text` spelled as the JSON escape for the Down arrow arrives whole,
    `1b 5b 42`. Neither `MCPTools` nor `MCPBridge` loses it:
    `Data(text.utf8)` keeps the escape byte and the input route carries
    it.
  - A raw escape byte inside the JSON string is worse than lossy:
    `JSONSerialization` rejects the whole line and `MCPBridge.run`
    continues past it, so the call vanishes with no reply. The shell
    spellings behave the same way.
  - A doubly escaped spelling types six literal bytes.
  The two bytes recorded on 2026-09-09 came from the calling MCP client
  stripping the control character out of the argument, not from kitterm.
  `facts.md` carried that wrong diagnosis and this round corrects it.
- **The fix is right anyway, and better for the reason.** `send_input`
  takes a `keys` array naming `up`, `down`, `left`, `right`, `enter`,
  `escape`, `ctrl-c`. A key travels by name because a JSON string is not
  a safe carrier for a control byte in either direction: a client that
  strips it yields two characters, a client that passes it raw breaks the
  line. `enter` maps to the route's `?enter=1`, so the daemon still
  chooses carriage return or line feed by what reads the terminal.
  `text` is untouched for every existing caller.
- visible: corpus request `01-arrow-key.md` satisfied live through
  `.build/debug/kitterm mcp`, with no `curl` and no shell: the mark moved
  from `No, exit` to `Yes, I trust this folder` with `keys:["down"]`
  (three bytes), and `keys:["enter"]` opened Claude's prompt.
- persistent: three files. `MCPSendKeysTests` adds seven cases.

## Reflection

The goal named a cause it had not verified. Its evidence was a symptom
seen once, from inside the client that caused it. A goal's objective is
read by every round of that goal, so a wrong cause there is expensive.
The rule to draw: an objective states the symptom it measured and names
a suspected cause as suspected.

cheap half; the rule is the valuable half, and it is in `facts.md`.
