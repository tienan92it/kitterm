## Effects

- **Four cases, not three.** The plan said the reading half tells a clean
  end from an unrecorded one. The crew found that the record has three
  states and "no record at all" is a fourth, and it kept `takeover` as
  its own value rather than folding it into clean. Its reasoning: the
  goal requires three cases to be told apart, and a clean-or-unrecorded
  pair cannot say which of the two clean-looking ones happened. Capability
  3 branches on `unrecorded` exactly, so the third value costs it nothing
  while the feed keeps the goal's distinction.
- **What each case emits.**
  - unrecorded: the previous run ended with no recorded reason, naming
    its pid, when it was last alive, and how many sessions it held.
    `previous=unrecorded` plus `previousPid`, `previousAliveAt`,
    `previousSessions`.
  - clean: ended cleanly with its reason and time. `previous=clean` plus
    the same keys and `previousEndedAt`.
  - takeover: handed over in place, with the session count kept.
    `previous=takeover` plus the same keys.
  - no record: one log line, and **no `previous` key at all**. The
    absent key is the absent record, so no consumer needs a fourth
    branch. The log line still exists, because a human reading
    `server.log` after a kill must be able to tell "the file was missing"
    from "the reading half never ran".
- **Naming.** The keys are prefixed `previous` because `pid` already
  means this run's pid on that event. Every existing key of
  `daemon.started` stays, so a client that reads only `epoch` is
  untouched, and a test pins that.
- persistent: five files. `PreviousRunReportTests`, ten tests, each of
  the four cases asserted twice, once on the log line and once on the
  event keys. Two of them drive real processes on one state directory: a
  `SIGKILL` then a start, and a `SIGTERM` then a start. The killed one
  spends thirty seconds waiting for the refresh to put the session count
  into the record, which is the only way to prove the refresh, the kill
  and the report compose, and it matches the corpus fixture of two
  sessions lost.
