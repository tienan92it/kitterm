## Effects

- behaviour: every workspace, project and goal heading carries its
  dollars and its cache share. A project reads its bucket from
  `GET /api/usage/daily` by root; a workspace sums the buckets its
  directory holds. The panel shows the total, marked "if billed at full
  API rate", one SVG bar a day, and two radio rows, `[x] cost [ ] tokens`
  and `[ ] 7d [x] 30d [ ] 90d`. An empty range still draws the axis and
  says the range is empty.
- The crew settled four questions inside its authority:
  - **A goal's cost has no route.** The rollup keys on a transcript's
    cwd; a goal is a set of round records. So `KnowledgeSummary` sums the
    `- Cost:` line of every `rounds/NNN.md`, the line `LOOP.md` defines
    and the foreman writes from `GET /api/archives/<id>/cost`. The three
    fields are absent when no record carries the line, so a goal that
    predates the bill prints nothing rather than a zero. `kitterm goal
    cost` reads the same line through the same parser.
  - **Watch grade.** The knowledge route already answers at watch grade,
    and so does the record file that holds the line, so the summed number
    adds nothing a watch reader could not open. Every heading number is
    absent together for a watch token, which the daily route refuses.
  - **Pinned shapes.** `Heading` and `GoalLine` are pinned by `toEqual`
    in `sessions-levels.test.ts` and `sessions-knowledge.test.ts`. The
    cost is looked up beside them, through `costLabel`, `projectUsage`,
    `workspaceUsage` and `goalCost`, rather than added as fields, so no
    existing assertion changed.
  - **A heading the report does not name prints `$0.00`.** Nothing is an
    answer, and an absent number would read as "not loaded".
