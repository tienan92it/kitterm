## Reflection

The measurement's grep predicted the `URLSession` files and missed the
13 socket files, because `SOCK_STREAM`'s type differs by platform rather
than being absent. Only the compiler finds that class, which is why the
module-level blockers had to clear first. The Linux pipe tars
`git ls-files`, so a new file must be added to the index before it
reaches the container; the crew staged its new support file before the
second run for that reason.
