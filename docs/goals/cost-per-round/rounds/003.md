## One thing the first line exposed

The route serves a live session, and the bill exists only after the
session ends, because Claude Code writes `cost-state` at exit. So at
collect time the foreman archives the session, which ends `claude` and
writes the bill, and then the session is no longer live and the route
answers 404. The foreman read this round's bill from the transcript
directly, through the path the archive keeps. Capability 4 reads
archives anyway, so the ledger is unaffected; but Collect's instruction
to read the live route is one step out of order, and the live daemon on
3418 is v0.28.0 and does not carry the route yet. Round 4 should serve
`GET /api/archives/<id>/cost` or say the ledger reads the transcript
through the archive's path, and the Collect sentence should say
"archive, then read".
