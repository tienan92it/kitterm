## Reflection

The round's hardest requirement was the one easiest to fake. "The band's
height does not change" can be written as a test that passes because the
fixture never stresses it. The crew stressed it: 2000 items and 60-character
nouns, measured on a live page, six cases, one number.

It also handled a Frozen file the honest way. Moving a DOM harness out of
`sessions-no-input.test.ts` produced a 169-line deletion in the diff, which
looks exactly like a weakened test. The crew said in its note that the
assertions were byte-identical and where they went, so the check took one
grep instead of a reading.
