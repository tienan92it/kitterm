## Effects

- **The reader takes one 64 KiB `pread` from the end.** `TranscriptBill`
  seeks to the end and reads back one window, so a 40 MB transcript costs
  the same as a short one. Only the last newline-terminated line is
  parsed. The crew measured the largest last line across 60 real
  transcripts at 1517 bytes, and a `cost-state` line grows about 170
  bytes per model, so the window has forty-fold room.
- **Three ways to have no bill, each named.** A last line longer than the
  window answers `noBill(lastLineTooLong)` and never guesses from its
  tail. A file that does not end in a newline is a writer mid-write and
  answers `noBill(lastLineIncomplete)`. A last line that is a turn is a
  session still running, or resumed after its last end, and answers
  `noBill(noCostStateLine)`.
- **Totals accumulate across resumes.** The crew found a transcript where
  a resume took the total from $5.03 to $9.63, so only the last line is
  the bill and an earlier `cost-state` in the same file is history.
- **The zeroed case is a bill of zero, and the crew was right to
  disagree with the plan.** Claude Code wrote a total and a real duration,
  nine hours on the transcript in question, and the corpus request prints
  the zeroed round as a row with numbers rather than a dash. The plan
  leaned the other way; the corpus settled it.
- **The route.** `GET /api/sessions/<id>/cost`, full grade only, read on a
  `DispatchQueue` and completed on the loop through `NIOLoopBound`.
  200 with `hasBill: true` and the transcript's own field names,
  unrounded, through `JSONEncoder`; 200 with `hasBill: false` and a
  reason for absent and truncated; 404 with no join, 404 when the file
  is gone with the path in the error; 403 for a watch token.
- **Fixtures are real.** `bill.jsonl` is the last three lines of the
  data-sources transcript, two models, $2.6361237500000003.
  `zeroed.jsonl` is the last four lines of a 6113-line transcript with
  `modelUsage: {}`. `truncated.jsonl` is the first cut inside
  `modelUsage`. They live under `Tests/Fixtures/` because SwiftPM warned
  on every build about unhandled files in the test target, and
  `Package.swift` is not the crew's to change.
- visible: **the foreman read a real bill through the route.** It
  started a scratch daemon, posted a `Notification` hook with the
  `X-Kitterm-Session` header naming the transcript of `fleet-catch-up`
  round 1, and read: `$7.14`, 28.6 min wall-clock, 10.6 min API time,
  6,066k input tokens of which 97% were cache reads, 49k output, 19k
  thinking. That is the first per-round cost this loop has ever had.
- persistent: nine files. `AGENTS.md` and `docs/architecture.md` describe
  the route and the reader.

## Reflection

The foreman's first check of the real transcripts read only 400 bytes of
tail and concluded that no crew transcript had a bill, because the
`cost-state` line is longer than that. Ten minutes went to a false alarm
before a wider read found `$7.14` on the first line it looked at. The
crew's reader takes 64 KiB for exactly this reason. The lesson is the one
the round itself encodes: a tail read has a window, and the window is
part of the claim.

`$7.14` for a round that removed noise from one row is the number this
goal exists to put beside every round. Whether it was worth it is now a
question with an answer in it.
