   caller `AccessPolicy.decide` graded full gets `token` and
   `watchToken`; a watch-grade caller gets
   `{"ok":true,"enabled":true,"url":…}` and no token of either kind.
   Before this, a **watch** token arriving through a correctly
   configured `--trusted-host` proxy was handed the **control** token,
   which spawns a shell: a privilege escalation in the configuration
   this goal recommends. Pinned three ways in `ExternalURLTests`, the
   watch case verified to fail on the old route by stash.

   `serve` writes it to `server.log`; `start`, `service install` and
   restart-under-the-service write it to the terminal.
